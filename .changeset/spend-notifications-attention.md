Notification channels can now hear about spend protection: unusual usage, usage alerts, a free daily limit running out, an app paused or resumed, and the monthly budget reached. Existing channels receive these events too; untick them in a channel's settings if you do not want them. Each message links to the app's Usage tab, says why, and gives dollar amounts as estimates at Cloudflare's prices. Home's "Needs attention" lists an app using far more than usual or that used up a free daily limit (with Pause app), a paused app (with Resume), and a free daily limit about to run out; the sidebar and the app's card show a dot for each. Members see these rows without Pause or Resume.
